# Claude Code Guidance - Fanaye Technologies Enterprise Frontend Next.js Boilerplate
- Author: Natinael Samuel (2026) <afritioalberts1216@gmail.com>
- Architecture: Next.js 16 App Router, React 19, Tailwind CSS v4, Shadcn base-nova (@base-ui/react).
- Visual Rule: Zero-Shadow Tonal Hierarchy. Never use heavy drop shadows. Use Sunlit Cream (#faf9f7), pure white cards with shadow-none, surface ivory headers, and hairline borders.
- Form Rule: Always use the container-query Field system for form inputs.
- Living Memory: Use Memo - Living Memory (natinaelsamuel.memo-living-memory) and keep memory/ updated.
- Commits: Use human, natural phrases. Never use robot commit prefixes (feat:, chore:, etc.).
